# Pendola Pass — registered geographic draft, 2026-10-12

Own 3072 × 3072 drawing, generated by `scripts/render-pendola-pass.py` with Pillow from `assets/maps/pendola-pass-geography.json`. The renderer reads coordinates, never reference image pixels. None of the four original photographs or diagnostic overlays is included in this repository.

## What changed from the first draft

The three zoom photographs were aligned to the overview with projective transforms, then visible structures were manually digitized in their original reference frame. The previous independently estimated rectangles/positions have been replaced by these transformed outlines. There are 70 traced features and 20 area/place labels (four main areas plus 16 additional names).

The receiving/station perimeter, Almatera station, observatory, loading roofs, southern named areas and southwest building group now share the same measured image reference plane. Text collision handling moves labels only, with leader lines back to the registered displayed-name areas. Labels do not assert surveyed building centres.

Assumed continuous north/south roads were removed. Wide western decks and two unresolved narrow routes are explicitly treated as transport corridors of uncertain road/rail type. Unknown old-town roofs and guessed researcher/tower/weather-station buildings were removed; their screenshot-confirmed names remain. Small gaps and obscured structures remain unfilled.

## Reference alignment — VERIFIED as an image operation

Method: OpenCV SIFT descriptors (16,000 requested features, contrast threshold 0.025), 3 × 3 Gaussian preprocessing, nearest-neighbour ratio 0.68, RANSAC homography with 4-pixel threshold. Matrices and computed statistics are stored in the geography JSON. The optional `scripts/register-pendola-references.py` reproduces the operation when the four private reference photographs are supplied.

These are **image-feature registration residuals in overview pixels**, not accuracy bounds for the manual drawing, surveyed game positions or distance/elevation measurements. Reprojected photographs and traced-outline overlays were visually inspected privately against the overview. The results support consistent spatial registration of the references.

## Manual geography — PARTIALLY VERIFIED

Visible names, relative arrangement and major observed outline positions were visually compared with the registered references. Manual vertices, partially obscured edges, line widths and broad relief/tree-cover areas remain approximate. Hatching is a drawing convention for tree-cover areas; no individual tree or rock coordinates are asserted. Frozen-channel segments are approximate and their rendered widths are symbolic. Some narrow routes cannot be classified confidently as road or rail.

The overview is a photograph of a game map and can retain perspective/lens distortion. Its image plane is the common reference, not a rectified survey of the game world. There is no verified world scale, elevation model or playable perimeter. The bottom corners are shown as outside the available photographic reference instead of invented terrain. German place names are retained; official translated place names have not been verified.

Open work: hidden details, finer terrain relief and individual building details where photographs obscure them; independent geographic/gameplay review; real Android device review. This remains a draft. Precise gameplay-marker placement must not rely on these manual outlines without additional verification.
