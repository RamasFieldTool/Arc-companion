# Known limitations

- RaidTheory is community data; in-game correctness is not guaranteed.
- Complete ARC drop coverage depends on the once-per-page RaidTheory `bots.json` request. If unavailable, the validated local fallback currently contains Bastion, Matriarch and The Queen only.
- `foundIn` coverage depends on the active item catalog. Missing `foundIn` is shown as missing data, never inferred.
- No building, container, coordinate or drop-rate data is invented.
- Unknown category and map IDs are displayed literally rather than mapped by similarity.
