# Anfrage zur Nutzung von Itembildern

Status: Entwurf, NICHT versendet.
Empfänger laut offizieller Embark-Medienseite für Lizenzanfragen: partnerships@embark-studios.com
Quelle: https://www.embark-studios.com/press

Subject: Permission to use ARC Raiders item thumbnails in a free community companion

Hello Embark team,

I'm Daniel, the creator of Ramas Field Tool, a free, unofficial community companion for ARC Raiders:
https://ramasfieldtool.github.io/Arc-companion/

The tool helps players search items and keep track of workshop requirements, collection goals and their own inventory. I would like to add small item thumbnails next to the item names to make the search easier to use.

Could you confirm whether we may use ARC Raiders item images for this purpose, and which conditions apply?

The community dataset at https://github.com/RaidTheory/arcraiders-data contains links to item images hosted by ARC Tracker. Its README explains that these are AI-upscaled versions of in-game screenshots and that the game imagery belongs to Embark. I do not want to treat the dataset's MIT license as permission from Embark to use the game artwork.

Ideally, we would download permitted images, resize/compress them into small thumbnails and host them with our own website, with the copyright notice and attribution you require. A free Android version is a future goal, so I would also like to know whether any permission would cover packaging these thumbnails with that app.

Would this use be covered by an existing fan-content policy or media-kit license? If the community images are not suitable, is there an official set of item icons we may use instead?

The tool would remain clearly labelled as unofficial and would not imply endorsement by Embark. I understand that any separate conditions of the image provider would also need to be respected.

Thank you for your help,
Daniel Rogge
Ramas Field Tool
