### Background

- Type: solid color drawable
- Proposed value: `#071011`

- Let the launcher apply its device-specific mask.

## Future Android resources

When the Android wrapper is generated, create:

- `res/drawable/ic_launcher_foreground.*`
- `res/drawable/ic_launcher_monochrome.*`
- `res/values/colors.xml` with the approved background color
- `res/mipmap-anydpi-v26/ic_launcher.xml`
- density-specific legacy launcher exports generated by Android Studio

Expected adaptive-icon structure:

```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@color/ic_launcher_background" />
    <foreground android:drawable="@drawable/ic_launcher_foreground" />
    <monochrome android:drawable="@drawable/ic_launcher_monochrome" />
</adaptive-icon>
```
