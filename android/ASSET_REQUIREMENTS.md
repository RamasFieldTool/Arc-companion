# Android and Google Play asset requirements

## Branding rule

Use the approved original Ramas Field Tool / ARC Companion logo as the only source artwork.

Do not:

- invent a replacement logo,
- recreate the logo from memory,
- use an unrelated ARC Raiders logo,
- imply official affiliation with Embark Studios,
- copy the official game's visual identity so closely that the app appears official.

Visual direction:

- worn 1980s retro-futurism,
- dark petrol or black,
- warm amber, orange and red accents,
- cream highlights,
- industrial but readable,
- strong contrast,
- own Ramas Field Tool identity.

## Required source

- [ ] Original approved logo at the highest available resolution
- [ ] Preferably with transparent background
- [ ] Confirmed right to use every included visual element
- [ ] A version that remains recognizable at small launcher-icon size

No production icon should be created until this source is available and visually confirmed.

## Android launcher icon

Prepare from the approved source:

- adaptive foreground layer,
- adaptive background color/layer,
- monochrome icon for supported Android launchers,
- legacy square icon exports generated by the Android build tools.

Safe-zone review:

- main symbol remains inside the adaptive-icon safe area,
- important text is not placed near the crop boundary,
- icon remains recognizable under circle, rounded-square and other launcher masks.

## Google Play assets

- Play Store icon: 512 × 512 px, PNG
- Feature graphic: 1024 × 500 px
- Phone screenshots: captured from the final Android build
- Optional tablet screenshots only after tablet layout verification

## Screenshot plan

Capture at minimum:

1. total requirements with active goals,
2. item search with a useful partial search term,
3. quest tracker,
4. blueprint tracker,
5. community map with an intentionally selected layer,
6. dark/light or German/English capability if space allows.

Screenshots must:

- use real app data,
- avoid invented functionality,
- show no private notifications or personal information,
- match the submitted build,
- remain readable on a phone-sized Play Store preview.

## Feature graphic concept

Primary brand: Ramas Field Tool  
Supporting line: Unofficial community field tool  
Visual focus: own logo plus clearly separated examples of items, quests, blueprints and maps.

Avoid placing essential information near the outer crop area. Do not describe features that are absent from the submitted build.
